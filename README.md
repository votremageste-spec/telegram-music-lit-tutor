# 🎵 МУЗЛИТ-РЕПЕТИТОР - Telegram Mini App

Приложение для подготовки учеников ДШИ и Лицея искусств к выпускному экзамену по русской музыкальной литературе.

## Возможности

- 📚 **Изучение композиторов** — биографии, произведения, аудиофрагменты, тесты
- 🎧 **Аудиовикторина** — тренировочный и экзаменационный режимы
- 📝 **Экзаменационные билеты** — реальные билеты с полными ответами
- ✍️ **Тесты** — проверка знаний по композиторам и терминам
- 🤖 **ИИ-ассистент** — на базе Groq API
- 📊 **Прогресс** — отслеживание результатов

npm run dev
